# Invoicer — Next.js 15 Frontend

Modern, high-performance web interface for the AI Invoicing & Financial Billing Platform built with Next.js 15 (App Router), React 19, Tailwind CSS, and shadcn/ui primitives.

## Features

- **App Router Navigation**: Modular page routes with server/client component boundaries.
- **shadcn/ui & Radix UI**: Accessible, responsive UI components (Dialogs, Tooltips, Tabs, Dropdowns, Sheets, Tables).
- **Interactive Analytics**: Revenue trends, collections half-donut gauge, status distribution, and receivables aging powered by Recharts.
- **Autonomous Financial AI Copilot**: Accessible via `Cmd+J` or `Ctrl+J` with interactive tool-use feedback.
- **Smart Receipt Scanning**: Drag-and-drop OCR parsing for expenses.
- **Adaptive Dark & Light Mode**: Theme switching with CSS custom properties.

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
